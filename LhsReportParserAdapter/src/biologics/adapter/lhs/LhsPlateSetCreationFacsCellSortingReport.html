Create a plate set with an LHS cell sorting report.

Example FACS cell sorting report format:

Clone Pool ID Plate Barcode
CP-5 DA0000000264
CP-5 DA0000000265
CP-5 DA0000000266
CP-5 DA0000000267
CP-5 DA0000000268

Note:

  • One plate is created for each barcode provided in the file.
  • The clone pools must already exist in Genedata Biologics.
  • The resulting plate set is a master plate set, and new antibody clone IDs are generated for each well of each plate.
