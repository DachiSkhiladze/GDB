GenericLabResultDataAdapter expects column based input file. Table header (first line) defines the file structure which means columns that identify parent (subject) entities as well as columns which contain the values of the attributes of the chosen Assay type.

Generic column-based format with entity id (cross entity-type) format example:

Cell Line Batch ID Host Cell Line Batch ID Vector Batch ID Protein Expression Batch ID Protein Purification Batch ID Sample ID Sample Barcode S B S/B IC50 S0 S/S0
CLIB-1 5.1 3.4
HCLIB-3 4 2
VB-6 3
PEB-1 6 2
PPB-8 5.1 2
SMP-1 3.4
sample bc 3.4

Note:

  • Parent (subject) entity or sample may be specified per row (per Lab Result).
  • Sample entity could either be identified by ID or by Barcode.
  • Column separator and the date format are configured by the system parameters table_export_import_format and format_pattern_date_with_time respectively and specified in the PARAMETER table.
  • All columns except the parent identifiers and the assay attribute columns will be ignored.
