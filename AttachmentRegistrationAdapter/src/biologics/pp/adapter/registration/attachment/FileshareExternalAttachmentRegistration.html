Any type of file can be uploaded and stored in an external system that is configured by a system administrator. A link to the attachment is displayed in Genedata Biologics.

Note:

  • The created by and modified by information that is automatically stored for each attachment refers only to the history of that attachment entity in Genedata Biologics.
  • If the attachment entity in Genedata Biologics is deleted and Uploaded via Genedata Biologics is Yes, the linked file is also deleted from the external system.
  • The file name of the uploaded file may not contain the hash symbol ('#'). Note that the hash symbol is commonly used to specify an anchor for references within files.
