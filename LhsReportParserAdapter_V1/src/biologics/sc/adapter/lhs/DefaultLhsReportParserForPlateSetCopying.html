Example liquid handing system report for copying a plate set: 

Parameter1,Parameter2,Parameter3,Type,#,Barcode
,,,Source,1,GDB0000331
,,,Source,2,GDB0000332
,,,Source,3,GDB0000333
,,,Source,4,GDB0000334
,,,Destination,1,GDB00009887
,,,Destination,2,GDB00009888
,,,Destination,3,GDB00009889
,,,Destination,4,GDB00009890

This adapter expects a comma-separated text file (csv) as input. The uploaded file should contain at least six columns, e.g.: 

Parameter1,Parameter2,Parameter3,Type,#,Barcode
The names of the columns are irrelevant in this adapter, only the order of columns is of importance.
  • The first three columns are silently ignored by this adapter.
  • Column four (Type in the example) must contain a keyword to identify the source plates. Supported keywords are stored in table PARAMETER under the key lhs_report_source_plate_identifiers. In the shipped configuration, every row containing the word Source is treated as source, all other are destinations for the copying process.
  • Column five (# in the example) must contain a group number that connects the source and destination plate pairs for the copy operation. The group number must match for the source and destination plate pair.
  • Column six (Barcode in the example) must contain the barcode of the plate.
