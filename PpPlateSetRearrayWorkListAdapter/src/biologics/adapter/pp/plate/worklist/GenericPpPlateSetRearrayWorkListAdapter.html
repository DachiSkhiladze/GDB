When generating a worklist file, a text file containing a list of Entity IDs separated by new lines may optionally be uploaded to limit the selection of entities. Below is an example of the content of such a text file:

PEB-265
PEB-262
PEB-263

Entities extracted from an uploaded file can belong to one of the following Entity Types:

  • Vector Batch
  • Cell Line Batch
  • Protein Expression Batch
  • Protein Purification Batch
  • Aliquot Group

If no such file is uploaded, the system will use the entire content of the source Protein Production Plate Set as selected entities.

The worklist items are tab-separated or comma-separated based on the system configuration. Below is an example of the content of a worklist file that the system will generate.

Source Plate Name Source Plate Barcode Source Well Well Content ID Status
All PPBs BC001 A03 PPB-9 True
All PPBs BC001 A04 PPB-10 True
